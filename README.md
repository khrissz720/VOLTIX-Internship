### 1. Video Game Industry Analysis

An analysis of video game sales data to explore market performance and identify patterns across genres, platforms, publishers, and geographic regions.

**Key deliverables:**
- Data cleaning and preparation.
- Sales distribution and trend visualizations.
- Genre, platform, and publisher comparisons.
- Power BI dashboard.

A data analysis project focused on Airbnb listings in New York City using the Airbnb NYC 2019 dataset.
