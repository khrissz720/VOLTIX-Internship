# Task 8 – Healthcare No-Shows Dashboard

## 1. Project Overview

This project focuses on analyzing healthcare appointment attendance and identifying patterns associated with patient no-shows.

The objective is to transform the original healthcare appointment dataset into a clean and structured dataset and develop an interactive Excel dashboard containing relevant KPIs, visualizations, and actionable insights.

The analysis focuses on:

- Appointment attendance and no-show rates
- Patient demographics
- Waiting time between scheduling and appointment
- SMS reminders
- Appointment weekdays
- Age groups
- Other relevant patient and appointment characteristics
